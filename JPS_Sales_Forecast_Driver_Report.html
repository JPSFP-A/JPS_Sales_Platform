5.1 Weather: how the driver is built

Weather % = temperature anomaly (°C above the 2023–2025 monthly reference climatology) × a blended sensitivity of 1.927%/°C. The blend is 2025-actual-GWh-weighted across per-class sensitivities from the source model, so residential carries most of the effect and industrial almost none:

The app's weather driver schema takes one company-wide value (segment is null), so this blend is applied uniformly to every class, RT70 included, even though the source model itself assigns RT70 zero real sensitivity. That is a known simplification of the schema, not an error in the number.

Source and its own caveat. Every figure above comes from JPS Integrated Forecast with AC-Solar Transition.xlsx (Downloads, supplied 25 Aug 2026), not from JPS billing history. The source model states its own limitation directly, for both years: "not verified against JPS billed actuals." This replaced an earlier flat, uncited 2% weather assumption used in Jul/Aug 2026, and is a real improvement in traceability, but it remains an external temperature forecast that has not been checked against how JPS load actually responded to past heat. Source: jps_macro_assumptions, driver_type='weather', source_note and justification columns.
What this report does not carry forward from the prior version. The prior driver report split residential growth into named sub-drivers (customer acquisition, prepaid, bucket migration, load decline) with specific GWh figures for each, built from a bespoke analysis of premises-connected trends and consumption-by-band changes through July 2026. That analysis has not been re-run against August, and the underlying engine has no single function that outputs those splits directly, so this version does not restate them. Rebuilding that level of detail is a further exercise, not a byproduct of this update.

7. Open Items

  • FY2026 no longer ties to the 19 August submission. Gap is +18.0 GWh and will keep moving as more months close. Whether to reconcile, resubmit, or hold the engine’s own number is a decision for FP&A, not something this report resolves.
  • Residential driver sub-split needs a refresh. Section 5’s warning applies: the customer-acquisition-versus-migration breakdown is not current. If that granularity is needed for the next board cycle, budget time to re-run it against August data.
  • Windalco is declining alongside Alcoa, -11.5 GWh into FY2027, and was not previously broken out as its own named line. Confirm whether it needs the same ownership attention Alcoa and MBJ received.
  • Kingston Free Port Terminal is resolved: assigned to Jean Waugh-Evans, no longer flagged as an unowned exposure. Removed from the risk register carried in the prior version.
  • Demand (kVA) forecast is a separate exercise, not covered by this update. See the Peak Demand Forecast scenario comparison for the elasticity and haircut treatment under review there.
